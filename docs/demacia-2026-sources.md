# 2026 Demacia Cup Global Invitational

근거는 사용자가 대화에 제공한 영문 발표문, 한국어 규정 발췌와 브래킷 슬라이드 3장입니다. 아래 링크는 해당 발췌에 포함된 출처이며 개발 환경에서 원문을 직접 열어 대조한 것으로 표시하지 않습니다.

확인한 발표 내용:

- 6개 지역 12팀. MSI 지역 순위의 1·2위는 3장, 3·4위는 2장, 나머지는 1장. 발표상의 배분은 LCK/LPL 3, LEC/LCS 2, LCP/CBLOL 1이다. 게임에서는 게임의 MSI 결과로 지역 배분을 계산한다. 지역 내 복수 참가팀 중 최고 성적을 기준으로 비교하며 구체적인 동률 추첨까지 공식 규정으로 주장하지 않는다.
- 월즈 진출팀은 제외하고 각 지역 기준의 최고 적격 팀부터 초청. LCK는 정규시즌 최종 순위, LPL/LCP는 챔피언십 포인트, LEC/LCS는 서머 순위, CBLOL은 일정상 스플릿2 4위. 거절하면 차순위로 승계.
- 온라인 10/3 R1 6경기 BO1, 10/4 1–0조 3경기 BO3, 10/5 0–1조 3경기 BO3, 10/6 1–1조 3경기 BO3, 10/7 0–2조 3팀 단일 라운드 로빈 3경기 BO3, 10/8 마지막 진출전 2경기 BO3.
- 0–2조 최하위 2팀은 탈락. 1위는 1–2조 3팀과 마지막 진출전을 치르며 승자 2팀이 진출. 2–0 3팀, 2–1 3팀, 마지막 진출전 승자 2팀으로 총 8팀.
- 1라운드는 먼저 추첨한 왼쪽 6팀에 대해 오른쪽 6팀을 배정하며 내전을 피한다. 이후 동일 전적끼리 추첨하고 그룹 스테이지 재대결을 피한다. 0–2조 라운드 로빈은 예외 경로다.
- 오프라인 전 경기 BO5. 10/12 M21·22, 10/13 M23·24, 10/14 M25, 10/15 M26, 10/17 M27.
- 2–0팀 첫 두 팀은 상단, 마지막 팀은 하단. 2–2팀은 각 브래킷에서 먼저 추첨한 2–0팀과 대결. 2–1팀 첫 팀은 상단의 남은 2–0팀과 대결하고 나머지 두 팀은 하단에서 서로 대결.
- RoFS는 1세트 먼저 추첨된 팀, 이후 직전 세트 패자. 오프라인 코치 보이스는 팀별 세트당 최대 3회, 회당 45초, 경기 정지와 세트 간 이월 없음.

구현 경계:

- 해외 지역의 실제 최종 순위·챔피언십 포인트·초청 팀명 자료가 없다. 실존 팀의 순위를 만들어내지 않고 `LPL CP 5위` 같은 순위 슬롯 NPC를 표시한다.
- 0–2조 삼자 동률의 세부 규정이 제공되지 않아 세트 득실 → 저장된 시드 추첨을 사용한다.
- RoFS의 선택은 선픽 자동 선택으로 간소화한다. 기존 게임의 3밴·글로벌 피어리스 모델을 사용하며 모든 실제 밴픽 절차를 재현하지 않는다.
- 코치 보이스는 자동으로 연결·종료 시각을 기록하는 중계 사건이다. 실제 음성 채팅이나 수동 실시간 코치 조작을 제공하는 기능은 아니다.
- EWC는 이후 별도로 제공된 자료를 사용한다. [EWC 자료](ewc-2026-sources.md) 참조.
