# 로스터 NPC 동반 성장

로스터 NPC는 팀 기본 전력으로 매번 생성되므로, 성장분을 `season.npcTraining[NPC ID].stats`에 따로 저장한다. `getRoster`는 기본 능력치에 저장 성장분을 더한 다음 월드 이벤트의 임시 보정을 적용한다. 읽기만 해서는 성장하지 않는다. 팀 기본 전력 재조정 후에도 성장분이 유지되며, 유저가 그 포지션으로 참가해도 NPC 성장분을 유저에게 이전하지 않는다. 명시적인 시즌 초기화는 새 시즌을 만들므로 성장 기록도 새로 시작한다.

- 듀오 연습: 선택한 로스터 NPC가 소통 +0.7, 숙련도 +0.4. 파트너 미지정 시 빈 포지션의 실제 로스터 NPC 한 명을 임시 파트너로 사용하며, 고정 듀오 설정은 바꾸지 않는다. 다른 유저를 선택했거나 NPC가 없는 5인 로스터면 추가 NPC 성장은 없다.
- 팀 훈련: 빈 포지션 로스터 NPC 전원이 운영 +0.4, 소통 +0.6, 피지컬 +0.2.
- 상세 스크림: 참여한 로스터 NPC 전원이 기존 스크림 초점별 성장량을 받는다. 스크림 결과는 훈련 전 전력으로 계산하고 성장분은 종료 후 적용한다.
- 개인 훈련·휴식 등을 선택한 유저 때문에 다른 NPC까지 자동 성장하지 않는다. NPC의 상태 수치는 기존 동작을 유지한다.
- 같은 턴 같은 종류의 합동 훈련은 한 NPC에게 한 번만 적용한다. 여러 유저가 같은 팀 훈련을 골라도 중복 누적하지 않는다. 상세 스크림은 기존 완료 여부 검사로 재실행을 차단한다.
- 각 능력치는 99를 넘지 않고, 실제 적용된 증가량만 저장하고 훈련/스크림 기록에 남긴다. 설정 변경으로 상한에 도달하면 새 증가분은 쌓지 않는다.

이전 버전 중계의 세트 사이 전략 재개 시 `npcTrainingVersions[turn]`을 저장된 규칙으로 고정한다. 해당 턴에 한해 새 성장 적용을 억제하여 이미 공개된 세트의 전력과 결과를 보존한다. 다음 턴부터는 새 훈련 성장을 적용한다. 기존 완료 경기에는 소급 적용하지 않는다.

검증: `test/npc-training.test.mjs`, 상세 스크림 API의 서버 재시작 검사, 전체 `npm test`.
