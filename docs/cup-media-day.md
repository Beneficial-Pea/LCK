# LCK 컵 미디어데이

새 시즌의 전년도 LCK 우승·준우승 팀은 서로 다른 두 팀으로 무작위 결정합니다. 시즌에 저장된 난수로 재현하므로 새로고침해도 바뀌지 않습니다. EWC 전년도 우승팀 추첨과는 별도입니다.

시즌 시작 전 미디어데이에서 우승팀은 바론, 준우승팀은 장로 대표로 나머지 8팀을 번갈아 지명합니다. 우리 구단이 대표라면 방장이 직접 지명할 수 있고, 다른 구단은 전력과 구단 판단으로 선택합니다. 지명별 기록과 최종 그룹을 확인할 수 있습니다. 자동 진행과 하루 정산은 남은 지명을 자동으로 마무리합니다.

완료 후 각 5팀, 그룹 간 25경기를 배정합니다. 가져온 경기 날짜·BO3/BO5·원본 출처는 유지하고 참가팀만 그룹 지명에 따라 바꿉니다. 각 팀은 상대 그룹 5팀과 한 번씩 경기하며 슈퍼위크 BO5도 한 번 치릅니다. 정규 리그의 최초 대진은 변경하지 않습니다. 이 지명 방식은 게임 내 규칙입니다.

이미 그룹 배틀이 진행됐거나 미디어데이를 지난 기존 저장에는 소급 추첨하지 않습니다. 원래 그룹·대진·결과를 유지합니다.

팀 선택 후에는 훈련 화면에 앞서 시즌 전 미디어데이를 엽니다. 그룹 편성 중에는 순위표 대신 지명 현황과 남은 자리를 표시합니다. 8팀 지명이 완료된 뒤 같은 게임 날짜의 첫 준비 일정으로 넘어가며, 이미 치른 경기는 다시 편성하지 않습니다.
