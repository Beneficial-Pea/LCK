# 불판·해설과 경기 흐름

사건별 불판 표현 520개와 경기 흐름에 따른 반응 88개를 추가합니다. 해설 표현은 사건별 208개와 흐름별 66개, 상황 기록은 흐름별 66개를 추가합니다. 총 신규 불판 템플릿은 608개, 해설은 274개입니다. 시리즈에서 같은 댓글이 반복되지 않도록 기존 기억을 유지하며, 큰 한타·스틸·골드 역전에는 댓글을 더 많이 배치합니다. 실제 커뮤니티에서 가져온 댓글이나 선수에 대한 외부 소문은 사용하지 않습니다.

경기 흐름 기록은 현재까지 공개된 골드·처치·목표·포탑·바론 버프만 봅니다. 현재 골드 우위 형성, 선두 교체, 3,000 이상 열세 뒤의 역전, 격차 축소, 스노우볼, 열세 속 교전 반격, 120초 안의 서로 다른 목표 교환, 바론 버프 중 포탑 파괴, 드래곤 누적과 영혼·장로 확보를 구분합니다. 골드 격차가 줄었을 뿐이면 역전이라고 표시하지 않습니다. 작은 오르내림을 반복된 역전으로 부르지 않도록 골드 선두 판정에는 1,000 차이 기준을 사용합니다. 표시된 수치는 해당 장면의 공개 골드와 일치합니다.

흐름은 상황 기록 안에 별도 강조 줄로 보여주고 해설과 분리합니다. 새 표현과 흐름 추적은 전투 난수·승패·KDA·밴픽·오브젝트 획득을 바꾸지 않습니다. 서로 다른 30개 BO5의 기존 결과와 비교해 확인했습니다. 향후 경기 결과와 최종 승자는 흐름 추적기에 전달하지 않습니다.

업데이트 전부터 전략 선택을 기다리던 저장은 공개된 전투 기록을 검증한 뒤 이전 세트의 원래 문장과 댓글을 유지합니다. 문구 은행이 바뀌었다는 이유로 다음 세트 진행을 막지 않습니다. 실제 처치·밴픽·점수 등이 달라지면 이전 결과를 덮어쓰지 않고 진행을 거부합니다. 이미 저장된 지난 경기에는 새 흐름을 소급 생성하지 않습니다.
