# 공지사항

로그인한 모든 가입자는 시즌 방 참가 여부와 관계없이 **MY CLUB → 공지사항**에서 공지를 읽을 수 있습니다. 모바일에서는 상단 더보기 메뉴에서 엽니다.

관리자 계정은 **공지 작성**으로 제목·분류(안내/업데이트/점검)·내용·상단 고정을 설정합니다. 각 공지의 수정·삭제 버튼으로 관리할 수 있으며 삭제는 한 번 더 확인합니다. 내용은 HTML 없이 줄바꿈을 유지한 텍스트로 표시합니다. 고정 공지를 먼저, 같은 고정 상태에서는 최근 등록 공지부터 표시합니다. 작성·수정 시 관리자 닉네임과 날짜(KST)를 표시합니다.

최초 설치 또는 기존 DB의 첫 업그레이드 때 기본 이용 안내와 최근 기능 업데이트 공지를 한 번 추가합니다. 이후 관리자 수정·삭제는 재시작과 재배포에도 유지하며, 기본 공지를 매번 다시 생성하지 않습니다. 공지도 기존 SQLite DB와 온라인 백업에 포함됩니다. Render에서는 해당 DB를 영구 디스크에 저장해야 재배포 후에도 보존됩니다.

목록은 탭을 열거나 새로고침 버튼을 누를 때 갱신합니다. 다른 관리자가 먼저 고친 공지를 오래된 화면에서 덮어쓰거나 삭제하지 못하도록 버전을 검사합니다. 충돌 시 작성 내용을 별도로 보관하고 목록을 다시 확인합니다.

API: 로그인한 사용자의 `GET /api/notices`, 관리자의 `POST /api/notices`, `PUT /api/notices/:id`, `DELETE /api/notices/:id`. 수정·삭제에는 조회한 `revision`을 전달합니다. 서버에서 로그인·관리자 역할을 검사합니다.
