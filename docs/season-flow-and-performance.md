# 시즌 표시와 하루 진행 개선

- 진출 팝업은 저장된 stageKey로 진출 대상을 표시한다. Road to MSI → MSI, LCK 플레이인 → LCK 플레이오프, Cup 플레이인 → Cup 플레이오프, MSI 플레이인 → MSI 본선이다. 승패·진출 판단이나 기존 확인 여부는 바꾸지 않는다.
- 정규시즌 그룹 배정 후 레전드/라이즈 두 표에 각각 그룹 내부 1~5위를 표시한다. 배정 전에는 기존 전체 표를 사용한다. 누적 승패·세트득실과 그룹 배정은 저장 데이터를 그대로 사용한다.
- 프로필의 POM 횟수/100포인트 표시도 awards.ledger의 regular만 사용한다. total의 국제전·다른 대회 기록을 덧붙이지 않는다. 경기 수훈 선수의 내부 저장 키 pom은 호환성을 위해 유지하고, 국제전 카드에는 BO1의 POG, 시리즈의 POS, EWC·데마시아컵의 경기 MVP를 표시한다. 대회 전체/결승 MVP를 새로 수여하는 기능은 아니다.
- 캘린더 진입과 게임 날짜/시즌 변경 시 선택일·표시 월을 현재 게임 날짜로 맞춘다. 같은 날 다른 날짜를 탐색할 수 있고 오늘로 이동 버튼도 유지한다.

## 일상 선택

132개 사건의 두 선택지 효과를 모두 비교하고, 중복이던 27쌍에 행동에 맞는 다른 증가/회복/부담을 지정했다. 아직 답하지 않은 기존 사건의 미리보기에도 적용하며, 이미 답한 사건의 저장 효과는 유지한다. 미리보기와 실제 적용은 같은 서버 함수를 쓰며 기존 능력치·상태 상한을 따른다. 모든 수치가 상한/하한에 있으면 서로 다른 선택의 실제 추가 변화가 모두 0이 될 수 있다.

## 경기 보정

- 멘탈 65까지 기존 상태 불이익을 적용한다. 65 초과~99에서 컨디션·피로의 경기력 불이익 완화율이 0~30%로 증가한다. 기본 상태 수치, 스트레스 불이익, 피로에 따른 훈련 성장 감소와 상태 등급은 유지한다. 월드 이벤트를 반영한 유효 멘탈을 사용한다.
- 시그니처(mainChampion)는 경기 전력 +6%, 주력(pool)은 +3%, 등록 풀 밖은 기존 −6%다. 시그니처가 pool에도 있어도 보너스를 중복하지 않는다. 밴픽·선수 기록에는 실제 선택 챔피언에 해당하는 보정만 표시한다.
- 새 세트는 performanceVersion=1을 저장한다. 이미 시작한 중계의 전략 재개 시 matchPerformanceVersions를 원본 세트에 맞춰 고정한다. 버전 없는 기존 세트는 예전 멘탈/챔피언 규칙으로 재생성한다. 이전 엔진과 8개 규칙 조합의 드래프트·중계·결과가 완전히 같은지 별도로 확인했다.

## 행동 선택과 국제대회 구단 일정

카드를 누르면 기존 action API로 즉시 저장하며 별도 제출 버튼은 없다. 오늘 선택이 없으면 카드가 선택된 것처럼 표시하지 않는다. 저장 중 정산 버튼을 잠깐 비활성화한다. 서버의 턴·시즌 식별자로 지난 화면의 요청을 거부한다.

미선택자가 보일 때는 정산 직전 최신 방 상태를 다시 읽는다. 실제 미선택자가 있으면 명단·휴식 처리 안내를 한 번 보여준다. 명시적으로 계속 진행을 누를 때만 기존 npcTakeover 경로로 정산하며, 이미 선택한 다른 선수의 행동은 유지한다. 확인창을 연 뒤 날짜가 바뀌면 추가 정산하지 않는다. 서버가 미선택자를 묵시적으로 처리하도록 권한 검사를 완화하지 않는다.

2026 국제대회 스냅샷의 퍼스트 스탠드·MSI·EWC·월즈 전체 기간과 데마시아컵 기간을 구단 행사 금지 구간으로 사용한다. 참가 여부와 휴경일에 관계없이 새 행사를 해당 날짜에 배정하지 않는다. 기존 미래 행사도 재배치하지만 이미 완료된 날짜·효과는 보존한다.
