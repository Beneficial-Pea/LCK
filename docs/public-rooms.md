# 공개 모집방과 대기실 대화

- 새 대기실에서 공개 모집/비공개를 선택한다. 기존 저장 방은 비공개로 취급한다.
- 가입한 계정만 `GET /api/rooms/public`에 접근한다. 목록에는 대기 중이고 참가자가 1~4명인 공개방을 최대 50개 표시한다. 현재 화면에서 15초마다 갱신하거나 수동으로 갱신한다.
- 목록은 방 코드·이름·연도·날짜·난이도·인원·빈 포지션·본인 참가 여부만 반환한다. 선수 프로필·메모·초상화·대화·시즌 시드는 포함하지 않는다. 방 상세와 내보내기는 계속 참가자에게만 허용한다.
- 모집 중 포지션의 저장 캐릭터로 참가한다. 서버가 중복 포지션과 닉네임, 정원, 모집 종료를 다시 검사한다. 방장은 팀 선택 전 공개/비공개 전환이 가능하다.
- 전원이 준비하고 팀 선택으로 넘어가면 공개 모집을 종료한다. 공개방은 코드만 알아도 이 시점 이후 새로 참가할 수 없다. 기존 참가자는 다시 접속할 수 있다. 기존 비공개방의 코드 참가 동작은 유지한다.
- 5명을 채우지 않아도 시작할 수 있고 빈 포지션은 NPC가 맡는다. 마지막 참가자가 나가면 기존 정리 기능이 방과 대화를 삭제한다.
- 대기실 안에서는 오너 대화만 표시하며, 기존 오른쪽 아래 오너 채팅과 같은 API·대화를 사용한다. 다른 사람의 메시지는 입력 중에도 로그에 반영하고 임시 입력과 스크롤을 보존한다. 선수단/개인 메시지는 이 대화에 표시하지 않는다. 모든 채팅 입력은 Enter 전송·Shift+Enter 줄바꿈이며, 한글 조합 중 Enter는 전송하지 않는다.

검증: `npm test`, `npm run check`. 실제 UI 검증은 임시 서버를 실행한 뒤 `DATA_FILE=/tmp/파일.sqlite BASE_URL=http://127.0.0.1:포트 node test/public-rooms-browser.mjs`로 실행한다. 실제 서비스 DB를 테스트에 사용하지 않는다.
