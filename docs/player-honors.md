# 선수 배경·경기 수상·대회 현황

선수 등록 시 기본 선수, 신인, 주목받는 신예, 베테랑, 지난 시즌 올프로 중 하나를 고른다. 기본 능력치 65에 항목별 +1~2를 한 번 적용하며 생성 화면에 여섯 수치를 미리 표시한다. 서버가 보너스를 계산하므로 입력한 능력치나 중첩 보너스를 신뢰하지 않는다. 슬롯을 편집해도 이미 시작한 방의 선수는 바뀌지 않는다. ‘지난 시즌 올프로’는 배경 설정이며 올해 수상 이력으로 집계하지 않는다.

POM은 BO1/BO3/BO5 시리즈마다 승리 팀 한 명에게 부여한다. 실제 세트 KDA, 킬 관여율, 포지션별 기여, 오브젝트 스틸, 멀티킬을 합산하며 세트 MVP와 구분한다. 라이브 중에는 최종 넥서스까지 POM을 숨긴다. 상대 팀끼리의 요약 경기에도 POM과 선수 집계가 남는다. 선수별 시즌 누적 POM은 프로필 위에, 정규시즌 POM 순위는 시상식 창에 표시한다.

10월 1일 정산에 올해의 선수와 올프로 퍼스트·세컨드·서드를 발표한다. 올해의 선수는 정규시즌 POM 최다 수상자이며 동률이면 경기 기여도로 결정한다. 올프로는 포지션별 정규시즌 POM과 기여도를 비교하며 해당 포지션 최다 출전 세트의 40% 이상 출전해야 한다. 발표 결과는 이후 국제전 성적으로 바뀌지 않는다. 업데이트 전 저장의 개인 집계는 새 경기부터 시작하며 누락된 옛 경기 수를 표시한다.

트리플·쿼드라·펜타킬은 실제 처치 로그에 독립 시드로 붙인 시간과 연속 처치로 판정한다. 처치 간 10초가 넘거나 선수가 죽으면 연속 기록을 끊는다. 효과를 위해 처치를 추가하거나 전투 난수를 바꾸지 않는다. 상황 기록, 존댓말 해설, 불판, 멀티킬 배너는 따로 렌더링한다.

매 세트 양 팀이 각각 5개를 밴하고 현재 세트의 10밴은 중복되지 않는다. 상대 주력 픽 일부와 다른 챔피언을 함께 밴하여 모든 선수의 주력 픽이 항상 금지되는 상황을 피한다. 이전 세트에서 사용한 챔피언은 피어리스 금지 목록이므로 다시 밴하지 않는다.

홈의 LCK 순위 카드는 현재 대회에 맞춰 컵 그룹, 플레이인, 플레이오프, 국제전, Road to 대진표로 전환한다. 정규시즌에는 원래 순위표를 표시한다. 브래킷의 승자·패자 경로는 현재 저장의 라우팅만 사용하며 실제 경기의 과거 팀·점수를 미래 대진에 넣지 않는다. 스위스는 라운드별 추첨 경기만 표시하며 고정 진출 연결선을 만들지 않는다. 모바일에서는 대진표 내부만 가로 스크롤한다.

피로·컨디션·스트레스의 기존 경기력 계산을 공통 `readinessFor`로 묶고 화면에도 같은 값을 표시한다. 컨디션은 80~100% 능력 반영, 피로는 수치×0.11, 스트레스는 수치×0.07만큼 경기력을 낮춘다. 피로가 40을 초과하면 훈련 성장량 30% 감소, 70을 초과하면 65% 감소한다. 기본 능력치를 깎지 않으며 휴식으로 회복한다.

검증: `npm test`, `npm run check`, 임시 서버에서 `test/browser-smoke.mjs`와 `test/tournament-browser.mjs`. 브라우저 대진 검사는 별도 `DATA_FILE`과 `BASE_URL`을 설정한 테스트 서버에서만 실행한다.
