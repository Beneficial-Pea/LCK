# FIRST TEAM · 1군 생활

2026년 LCK를 기본으로 하는 한국어 텍스트 협동 시즌 게임입니다. 새 방은 2026 시즌으로 생성하며, 이미 저장된 2025 시즌은 계속 플레이할 수 있습니다. 빈 저장소에서 새로 구현한 버전이며, 기존 참고 사이트의 소스나 세이브를 가져온 버전이 아닙니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 패키지나 API 키는 필요하지 않습니다.

```sh
cd /workspace/LCK
npm start
```

기본 포트는 `3000`입니다. `PORT`, `HOST`로 변경할 수 있습니다. 개발 중 자동 재시작은 `npm run dev`, 검증은 `npm test`, 문법 검사는 `npm run check`를 사용합니다.

첫 화면에서 오너 이름과 선수 캐릭터를 저장하고 방을 만드세요. **선수 생성 단계에서는 팀을 고르지 않습니다.** 다른 참가자는 같은 서버 주소에서 자신의 캐릭터를 만든 뒤 초대코드로 참가합니다. 대기실에서 전원이 준비하면 방장이 팀 설명을 보고 하나의 소속 팀을 선택한 뒤 시즌을 시작합니다. 중복 포지션과 6번째 참가는 차단되고 비어 있는 포지션은 NPC가 맡습니다.

새 방의 NPC 전력 기본값은 **선택한 팀의 참고 전력에 맞춤**입니다. 직접 설정 모드도 선택할 수 있습니다. 예전 기본값 65로 시작한 기존 방은 **시즌 방 → 전력 점검**에서 방장이 팀 기본 NPC 전력으로 조정할 수 있습니다. 변경은 향후 경기에 적용하며 과거 경기·날짜·제출 행동·유저 능력치는 보존합니다. 전력 차이가 큰 약팀은 여전히 불리하고, 보정은 승리 보장이 아닙니다.

공개 인터넷 주소로 플레이하려면 [Render 무료 체험 배포](docs/render.md) 또는 [Railway 배포 안내](docs/railway.md)를 따라 서버를 배포합니다. 무료 Render 설정은 파일이 영구 보존되지 않으므로 장기 세이브에는 영구 디스크가 필요합니다. `Dockerfile`, `render.yaml`, `railway.json`을 포함했지만 외부 배포를 실행한 상태는 아닙니다.

## 저장과 공동 진행

- 캐릭터 슬롯 5개는 각 브라우저의 서버 세션에 귀속됩니다. 시즌에는 선택한 캐릭터의 복사본이 들어갑니다. 슬롯을 편집하거나 다른 슬롯을 선택해도 기존 시즌의 선수가 바뀌지 않습니다.
- 캐릭터 슬롯의 삭제 버튼은 확인 후 해당 슬롯만 비웁니다. 다른 슬롯과 참가 중인 시즌의 선수·성적·행동·채팅은 유지합니다. 삭제한 슬롯을 새 방에 사용하려면 선수를 다시 등록해야 합니다.
- PNG·JPG·WebP 프로필 사진을 선택·변경·삭제하고, 드래그·터치·가로/세로 위치·1~4배 확대로 보이는 부분을 정할 수 있습니다. 표시 사진은 256px·64KB 이하, 재편집용 사진은 긴 변 768px·64KB 이하로 압축합니다. 편집 원본과 위치는 본인만 조회하며 다른 참가자와 시즌 내보내기에는 최종 사진만 공개합니다. 과거 원본 없이 정사각형만 저장된 사진은 그 범위 안에서 편집하거나 새 원본을 올립니다. 슬롯과 시즌 사진은 별도이며 사진 변경으로 선수 ID·날짜·능력치는 바뀌지 않습니다.
- 대기실의 준비 버튼은 시즌 시작을 위한 준비 상태입니다. 시즌에 들어간 뒤 매일 제출하는 훈련 행동과는 별개입니다. NPC는 자동 준비되므로 혼자서도 시작할 수 있습니다. 기존에 진행하던 시즌을 대기실로 되돌리지 않습니다.
- 각 방은 날짜, 능력치, 관계, 제출 행동, 일정, 경기 결과를 독립적으로 저장합니다. SQLite 파일은 기본 `.data/game.sqlite`이며 `DATA_FILE`로 변경할 수 있습니다. SQLite의 WAL 파일까지 포함하는 안전한 백업을 사용하거나 서버를 종료한 뒤 데이터 디렉터리를 백업하세요.
- 쿠키로 식별하는 익명 오너 방식입니다. 같은 브라우저에서 새로고침·재접속하면 복원됩니다. 별도의 이메일 로그인·다른 기기에서 계정 복구·소셜 로그인은 구현하지 않았습니다. 시크릿 창 또는 별도 브라우저 프로필로 다른 유저를 시험할 수 있습니다.
- 준비 행동을 제출하고 정산 전까지 수정할 수 있습니다. 전원 제출 후 방장이 하루를 정산합니다. 미제출자는 방장이 명시적으로 NPC 대행을 선택해야 휴식으로 정산됩니다. 동시 정산 요청과 지난 턴의 늦은 제출은 거절됩니다.
- 솔로 자동 진행은 최대 7일이며 우리 팀의 경기·고정 활동 당일에 멈춥니다. 2명 이상인 방에서는 사용할 수 없습니다.
- 명시적으로 방을 나가면 다음 참가자에게 방장 권한이 넘어갑니다. 단순 연결 끊김·탭 종료는 퇴장으로 보지 않습니다. 방장이 재접속할 때까지 데이터와 제출 상태를 보존합니다. 잠시 부재할 때는 먼저 권한을 이전하세요.
- 초대코드는 참가 권한입니다. 알고 있는 사람에게만 공유하세요. 외부 서비스 배포 시 HTTPS를 사용하고 `COOKIE_SECURE=1`을 설정하세요. TLS 종료·백업·프로세스 재시작은 배포 환경에서 관리합니다. 이 저장소는 대규모 공개 서비스 운영을 위한 계정·차단·과금 시스템을 포함하지 않습니다.

## 경기와 일상

하루 한 번 선택한 훈련·분석·팀 훈련·듀오·휴식·외출을 정산합니다. 기본 능력치와 컨디션·피로·스트레스는 별도이며 경기 판정에 함께 반영됩니다. 상대별 능력치와 성향, 난이도, 랜덤 시드는 시즌 생성 시 고정합니다. 상대 초기 전력은 공개된 2026 완료 경기 결과를 Elo로 계산해 게임 수치로 바꾼 프리셋입니다. 공식 선수 평가가 아니며 운영 성향은 별도의 게임 설정입니다. 자료 기준과 공식은 [2026 근거 문서](docs/2026-sources.md)에 있습니다.

숙소 생활에는 연습실·거실·주방·분석실·헬스장·매니저실·경기장·PC방·편의점·식당·카페·클리닉의 서로 다른 도트 장면이 있습니다. 현재 장소에 있는 실제 참가자와 NPC를 구분해 표시합니다. 장면을 클릭하거나 포커스한 뒤 WASD·방향키로 내 캐릭터를 옮길 수 있고 좌표는 서버에 저장됩니다. 캐릭터를 누르면 프로필을 볼 수 있습니다. 장소 이동·화면 안 이동은 턴이나 능력치를 바꾸지 않습니다. 참고 이미지의 교실 UI나 그림은 복제하지 않았습니다.

경기는 먼저 승자를 추첨해 해설을 붙이는 방식이 아닙니다. 라인 주도권, 퍼스트킬, 갱킹, 러브샷, 시야, 오브젝트, 한타가 누적되어 마무리 조건에 도달합니다. KDA는 실제 기록된 킬·어시스트로 집계합니다. 같은 시드와 상태는 같은 결과를 만듭니다. 세트별 중계와 가상 커뮤니티 반응을 순서대로 읽을 수 있습니다. 게임 내 교전은 텍스트 단계의 추상 모델이며 실제 LoL 전투 엔진·패치 데이터 재현은 아닙니다.

우리 팀 경기일에 정산하면 서버 시계 기준의 **게임 시간을 압축한 실시간 중계**가 시작됩니다. 공개된 교전만으로 현재 점수·KDA·불판을 표시하고, 다음 세트·최종 승자·순위·날짜는 미리 공개하지 않습니다. 재접속해도 같은 중계에 이어지며 마지막 장면 이후 날짜와 결과가 한 번 확정됩니다. 이미 끝난 경기는 다시보기로 읽습니다. 중계 중 사진·이동·채팅 변경은 유지되고 새 행동 제출과 중복 정산은 차단됩니다.

솔로킬·역갱·정글 침투·바텀 교전·다이브·시야 끊기·오브젝트 교환과 스틸 등의 사건 경로, 사건 수·시각·마무리가 시드마다 달라집니다. 드래곤·바론의 등장/재등장 시간과 킬 기록을 함께 계산합니다. 불판은 약 300개의 작성된 커뮤체·욕설·플레이 비판 문구를 사건·닉네임·챔피언과 조합하며, 실제 커뮤니티나 뉴스에서 가져온 댓글은 아닙니다. 댓글 선택용 난수는 경기 판정과 분리합니다.

10팀의 NPC 50명은 서로 다른 가상 닉네임을 사용합니다. 같은 방의 유저 닉네임 중복은 대소문자·전각·보이지 않는 문자를 정규화해 차단하고, NPC와 유저 이름이 겹치면 NPC 쪽만 구분합니다. 기존 완료 경기 기록의 이름은 수정하지 않습니다.

오너 채팅은 실제 유저 대화, 선수단 채팅은 캐릭터 RP입니다. 둘 다 훈련 효과나 관계 점수를 자동 변경하지 않습니다. 상태·관계는 명시적으로 선택한 하루 행동으로 바뀝니다. 선수단 채팅에서 `@코치`, `@매니저`, `@분석관`을 부르면 정해진 짧은 응답을 합니다. 개인 메시지는 발신자와 수신자만 서버에서 조회할 수 있습니다. 경기 불판은 게임 사건으로 만든 가상 반응이며 외부 커뮤니티에서 수집하지 않습니다.

로스터 NPC와 하루 듀오 활동의 임시 파트너는 별개입니다. 고정 듀오를 직접 선택하지 않았다면 활동 후 임시 파트너는 해제되고 활동 기억만 남습니다.

## 시즌 랜덤 이벤트

하루 정산 시 약 15% 확률로 각 방의 리그 전체에 가상 사건이 발생합니다. 우리 팀·상대 팀·NPC·확정된 국제대회 팀이 같은 규칙의 대상이 됩니다. 같은 시즌 시드와 턴은 같은 사건을 만들고, 새로고침·채팅·사진 변경으로 다시 추첨하지 않습니다. 기존 시즌에도 다음 정산부터 연결되며 새 시즌을 만들 필요는 없습니다.

- 챔피언 너프: 예를 들어 아리를 시그니처로 쓰는 선수 전원에게 라인전 −1, 14일.
- 챔피언 상향: 같은 시그니처 선수의 숙련도 +1, 14일.
- 손목 피로 관리: 해당 선수의 피지컬 −2, 7일.
- 팀 합류 콜 정리: 해당 팀의 소통 +1, 7일.
- 가상 인터뷰 해프닝: 시스템이 생성한 가상 NPC만 대상으로 멘탈 −2, 7일. 실존 선수의 실제 논란이나 뉴스로 표현하지 않습니다.

이벤트는 리그 소식과 활동 기록에 남고 영향 선수·팀·수치·남은 기간을 표시합니다. 기본 성장 능력치는 보존하면서 별도의 `effectiveStats`를 계산해 실제 경기 판정에 사용합니다. 기간이 끝나면 훈련으로 얻은 성장을 취소하지 않고 이벤트 효과만 해제합니다. 기본 상대 전력 프리셋은 고정이며 이벤트로 그때의 경기 적용 능력이 달라질 수 있습니다.

## 일정과 진출 규칙

새 시즌의 기본값은 한국시간 기준 **2026-01-12~2026-11-15, 308턴**입니다. 기존 2025 시즌은 **2025-01-13~2025-11-09, 301턴**으로 유지합니다. 현실에서 하루를 기다리지 않습니다. 2026은 90경기의 R1~2, 5경기의 MSI 선발전, 40경기의 후반 그룹 정규시즌과 플레이인·플레이오프를 사용합니다. 2025의 후반 그룹 60경기와 서로 혼합하지 않습니다.

**2026은 Cup 결승 진출 두 팀이 퍼스트 스탠드에 갑니다.** 2025 시즌만 Cup 우승팀 1팀 조건을 사용합니다. 정규시즌 상위 6팀이 Road to MSI에 참가하고 그 대회의 시드를 획득한 2팀이 MSI에 갑니다. 월즈는 기본 3시드이며 **사용자 요청에 맞춰 LCK 팀이 MSI 결승에 진출한 경우에만 4시드를 받는 변형 규칙**을 유지합니다. 이 추가 시드 조건은 공식 규정을 완전히 재현한 것이라고 설명하지 않습니다.

2026 날짜는 독립된 공개 경기 캘린더에서 확인한 시작일을 사용합니다. 후속 진출자·대진은 게임 결과에 따라 바뀌며, 조 편성·동률 처리·지명·일부 시드 경로는 간소화합니다. 공개 캘린더 확인과 공식 규정 원문 대조는 구분합니다. 공식 사이트 직접 접근은 현재 환경에서 차단되어 있습니다. 상세 범위와 출처는 [2026 근거 문서](docs/2026-sources.md), [기존 2025 규칙](docs/rules.md), 게임 내 해당 시즌의 규칙 화면에 표시합니다. 상대 팀은 LCK 10팀 목록에 고정되어 있고 전력·성향은 시즌 시작 전에 조절할 수 있습니다.

## 구조와 비용

- `server.mjs`: HTTP API, 익명 세션, 방 권한, 정산 요청, 정적 화면
- `lib/store.mjs`: SQLite 영구 저장, 트랜잭션, 개인 메시지 조회 권한
- `lib/season.mjs`: 일일 행동, 시즌 일정, 팀 순위, 진출·탈락, 관계
- `lib/season2026.mjs`: 2026 날짜·대회 경로, 기존 2025와 별도 진행
- `lib/match.mjs`: 시드 기반 사건·밴픽·세트·시리즈 시뮬레이션
- `lib/live-match.mjs`: 미래 결과를 비공개로 보관하는 서버 시계 중계와 최종 정산
- `lib/commentary.mjs`, `lib/nicknames.mjs`: 사건별 반응 문구와 중복 없는 가상 닉네임
- `lib/balance.mjs`: 전력 진단과 기존 방의 명시적 NPC 보정
- `lib/portrait.mjs`: 사진 형식·크기 검사
- `lib/world-events.mjs`, `public/world-events.js`: 리그 전체 랜덤 사건·유효 능력치와 표시
- `lib/team-profiles.mjs`, `data/calendar-2026.json`: 경기 기록 기반 초기 전력과 일정 근거
- `public/scenes.js`, `public/scenes.css`: 장소별 원본 도트 장면과 캐릭터 표시
- `public/`: 별도 빌드 없는 반응형 화면
- `test/`: 사건 정합성, 시즌 진행, 실제 HTTP 다중 세션 검증

외부 생성형 AI를 호출하지 않습니다. 사용량당 AI 비용은 발생하지 않으며 서버 실행·디스크·네트워크 비용은 배포처에 따릅니다. 방 데이터는 같은 서버 인스턴스의 참가자들이 공유합니다. 인스턴스를 여러 대로 분산하는 구성은 지원하지 않습니다.

## 일상 이야기와 통합 채팅

우측 하단 채팅창의 오너칸과 팀 카톡방에서 대화합니다. 메인 화면 전환 없이 탭별 초안을 유지하며, 오너 말과 선수 말은 별도 채널로 저장합니다. 기존 개인 메시지는 서버에 보존하지만 이 창은 요청에 맞춰 두 단체 채널만 제공합니다.

비경기일 정산 시 선택 행동·현재 장소를 바탕으로 팀 NPC나 스태프와 120종의 일상 사건이 생깁니다. 최근 60개 유형을 우선 피하고, 같은 상대와 만난 기록을 후속 대화에 반영합니다. 다음 턴 정산 전 응답을 한 번 선택해 관계를 쌓을 수 있고, 함께하는 응답은 스트레스1을 낮춥니다. 숙소 화면과 오늘 화면에 최근 사건·응답·친밀도가 남습니다. 실제 참가자의 자유 채팅을 자동으로 관계 변화로 해석하지 않습니다.


2026 팀 고정 활동은 월 3회 후보를 기준으로 광고 촬영, 제품 방송, 화보, 인터뷰, 팬미팅, 사인회, 팀 콘텐츠, 검진·장비 점검을 미리 편성합니다. 팀 경기와 겹치면 다음 빈 날짜로 옮기고, 오늘 화면·캘린더에 표시합니다. 정산 시 전원 참여 기록과 피로·스트레스 변화가 저장되며 완료한 날짜는 다시 이동하지 않습니다. 기존 세이브는 남은 날짜의 일정만 받습니다. 실제 구단의 광고 일정을 수입한 것이 아닌 게임 내 팀 활동입니다.

불판에는 기존 문안 외에 장면별 288개, 잡담·질문 81개와 추가 상황 반응을 넣었습니다. 평상시 4~7개, 한타·스틸·슈퍼플레이·세트 종료에는 7~10개를 기본으로 선택하고 가끔 잡담이 붙습니다. 시리즈 안에서 같은 댓글을 다시 쓰지 않으며 우리 팀 최근 댓글 600개도 피합니다. 별도의 해설 160개는 현재 공개된 장면에서만 선택합니다. 댓글·해설 난수는 경기 판정과 분리되어 결과나 KDA를 바꾸지 않습니다.


2026 데마시아컵 글로벌 인비테이셔널은 사용자가 제공한 발표문·브래킷 슬라이드를 기준으로 27경기를 추가합니다. 10월3~8일 온라인 변형 스위스 20경기, 12·13일 8강, 14·15일 4강, 17일 결승입니다. MSI 지역 성적에 따라 3·3·2·2·1·1장의 초청권을 나누고 월즈 참가팀을 제외합니다. LCK 초청 순서는 레전드·라이즈 그룹 내 성적을 사용한 정규시즌 최종 순위이며, 개막 전 방장의 초청 거절은 차순위 팀으로 승계합니다. 해외 실제 참가팀 이름과 포인트 자료는 없어 순위 슬롯 NPC를 사용합니다. 세부 근거와 미확인 항목은 [데마시아컵 자료](docs/demacia-2026-sources.md)에 기록합니다.

첫 라운드 내전·온라인 재대결을 피하고, 0승2패조 3팀의 라운드 로빈 1위만 마지막 진출전에 합류합니다. 오프라인은 모두 BO5이며 RoFS는 추첨 선지명 팀에서 시작해 직전 세트 패자에게 넘어갑니다. 게임에서는 선픽을 자동 선택합니다. 코치 보이스는 자동 중계 사건으로 팀별 세트당 최대3회·각45초, 경기 정지와 횟수 이월 없이 재현합니다. 기존 2026 저장은 대회 시작일까지 미래 대진을 한 번 추가하고 시작일이 지난 저장은 소급 변경하지 않습니다.

오늘 화면의 선수단 소식은 행동 선택 옆에 붙습니다. 선택 중인 행동과 실제 제출한 행동을 즉시 구분해 표시하고, 정산하면 최근 활동·리그 소식을 갱신합니다. 데스크톱에서는 옆 열에 고정되며 모바일에서는 행동 정산 영역 바로 아래에 위치합니다.


경기 중계는 각 장면을 `상황 기록`과 `해설 중계`로 나눠 표시합니다. 기록은 기존 사건·처치 데이터를 서술하고, 존댓말 해설은 독립된 `casting` 필드에 저장합니다. 해설 문안은 426개로 늘렸고 상황 기록에도 처치·한타·갱·다이브 등의 표현을 추가했습니다. 기존 저장에서 해설이 상황 본문에 합쳐져 있어도 별도 해설 필드가 남아 있으면 화면에서 정확히 그 문구만 분리하며 기록 원본은 수정하지 않습니다.


Road to EWC는 이제 정규시즌 상위 4팀 초청과 별도입니다. 우리 팀을 제외해 전년도 우승팀을 시즌 시드로 정하고 저장합니다. 전년도 우승이 LCK면 해당 팀을 제외한 9팀, 해외면 LCK 10팀이 예선에 참가합니다. 1라운드 45경기의 순위로 시드를 고정하고 하위 2팀(10팀이면 4팀)은 플레이인을 치릅니다. 8팀 더블 엘리미네이션에서 진출전 2경기만 BO5, 나머지는 BO3입니다. 중복 자격은 예선 3위가 승계합니다. 4개 풀·지역 중복 없는 GSL, 결승 전 같은 그룹 재대결을 막는 8강, 3위 결정전·RoFS도 적용합니다. 새 방 및 예선 시작일까지의 저장에 적용하고 이후 저장은 기록을 보존합니다. 근거·게임용 변경은 [EWC 자료](docs/ewc-2026-sources.md)에 정리했습니다.

2026 시즌의 대회 사이에는 선수단 휴가를 편성합니다. 가족 방문·집에서 쉬기·여행·조기 복귀 24개 문안을 최근 기록과 다른 내용으로 선택해 저장합니다. 휴가 중에는 훈련·대화 선택을 받지 않고 방장이 하루 또는 같은 휴가의 남은 날을 넘깁니다. 능력치는 성장하지 않으며 컨디션·피로·스트레스만 회복합니다. 경기와 겹치는 날에는 쉬지 않고, 광고 등 고정 활동은 휴가 밖으로 조정합니다. 휴가와 회복은 공유 일정에 한 번만 반영됩니다.

홈 상단에서 내 선수의 사진·닉네임·6개 능력치를 확인합니다. 현재 적용 수치와 패치에 따른 기본값 차이를 함께 표시하며 정산 후 갱신합니다. 플레이 중 리그 소식·불판의 ‘가상 사건/실제 뉴스 아님’ 알림은 제거했고, 과거 이벤트에 저장된 같은 안내도 표시할 때만 정리합니다. 뉴스의 기간·영향 선수·능력치 증감은 유지합니다.
